# What Can I Make?

What Can I Make? is a Python application that helps users find recipes based on ingredients they already have.

## First Release

The first version will allow users to:

1. Enter ingredients
2. Search for matching recipes
3. View basic recipe information

## For Testing:

TO run the tests, use:

py -m pytest
